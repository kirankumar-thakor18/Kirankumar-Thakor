### Phishing Triage & Threat Intelligence Bot

**SOC / Threat Intelligence**

Flask-based phishing email triage tool that automates the first steps a SOC analyst performs on a suspicious email. It parses `.eml` files, extracts IOCs, enriches them with threat intelligence (VirusTotal, AbuseIPDB), checks SPF/DKIM/DMARC results, and produces an explainable 0–100 risk verdict with downloadable JSON/CSV reports and scan history.

**Tech:** Python · Flask · VirusTotal API · AbuseIPDB API · SQLite · Docker · Bootstrap · pytest

[View Repository →](https://github.com/kirankumar-thakor18/Phishing-Triage-Bot)
